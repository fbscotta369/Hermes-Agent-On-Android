# AIIA Multi-Agent Autonomous Framework

## Purpose

Defines how AI agents work in this repo.

## Core Rules

- Work autonomously.
- Preserve user changes.
- Use A2A files for handoff.
- Run validation when available.
- Document blockers clearly.
- Avoid destructive commands.
- Treat this repository as private by default.
- For commercial repos, optimize for a current MMR that can generate revenue movement within 7 days or less.
- If revenue movement cannot happen within 7 days, reduce scope or park the repo.
- Do not create new costs or expose confidential owner context.
