# A2A-Goal — Project Goal

## Purpose

Single-sentence project objective.

## Goal

Package the Nous Research Hermes Agent for reliable, one-command installation
on Android devices via Termux + proot-distro Ubuntu.

## Success Criteria

- One-liner installer works on clean Android 11+ devices
- All launcher commands exist and function after install
- `hermes-doctor` passes all checks
- Updates are possible without full reinstall

## Non-Goals

- This repo does NOT contain the Hermes Agent application code
- This repo does NOT maintain Python dependencies
- This repo is NOT a general-purpose Termux packaging framework
