# A2A-GTM — Go-To-Market

## Purpose

Product positioning and distribution notes.

## Status

This is an **open-source installer/packaging project**. It is not a commercial
product with revenue targets. GTM work is limited to documentation and
community support.

## Distribution

- Primary: `curl | bash` one-liner from GitHub raw content
- Secondary: Manual clone + run installer
- Update mechanism: `hermes-update` (self-updating launchers)

## Audience

- Android power users
- Termux enthusiasts
- People who want to run AI agents on mobile devices
